# Design write-up

FastAPI accepts bounded multipart/raw uploads and WebSocket PCM/G.711 chunks. Native code decodes WAV and telephony samples; a bounded FFmpeg subprocess decodes M4A, MP3, Opus, and other containers while probing source codec and rate. All signals become mono 16 kHz float PCM. Quality checks measure usable speech, loudness, clipping, bandwidth, spectral shape, low-frequency noise, and SNR. Insufficient speech abstains before model execution; degraded speech lowers confidence. A speech-evidence window avoids selecting a louder stationary engine-noise interval.

The working offline baseline runs one pinned SpeechBrain ECAPA embedding and commercially permissive griko gender/age heads. It is reproducible and CPU-friendly, but its age MAE and logistics-domain shift are material. The production target is WavLM Base+ with our own consented, noise/codec-augmented logistics training, a direct ordinal age-bracket head, and held-out calibration. The included ONNX adapter fails closed until that owned artifact is mounted. audEERING devAIce is the turnkey paid alternative; public audEERING weights are noncommercial.

Persistence is explicit per request: `none` (default), `result`, or consent-gated `result_and_audio`. PostgreSQL stores queryable results and manifests; S3 stores voice bytes. Live 250 ms logical chunks are coalesced into approximately one-second objects while retaining sequence, offsets, lengths, and SHA-256, reducing object PUT volume. TTL cleanup and delete-now remove objects before metadata.

At 1,000 calls, regional stateless ingestion pods feed bounded VAD buffers to GPU workers that micro-batch WavLM inference. Queue deadlines, backpressure, admission control, and autoscaling on delay/GPU utilization protect latency. Managed PostgreSQL and S3 scale independently; one retention-worker pool claims deletion jobs. Caller-only channel routing, tenant auth, KMS, private networking, and body-log exclusion are production gates.
